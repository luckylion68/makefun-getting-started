## 怎么参赛（以一次真实提交为例）

1. **挑比赛**：看奖池、截止时间、参赛人数，选一个你感兴趣的。短平快的优先（比如新闻图 2 天截止）。
2. **下载 kit**：每个比赛页都有一个 kit（命令行工具），下载解压后就能用。
3. **让 AI 写**：把任务描述清楚，让 AI 在本地写出作品（游戏、预测程序、图片生成脚本都可以）。
4. **自检**：kit 自带的 `check` 会逐项核对（有没有跑通过、有没有留痕、记录全不全），全部通过再交。
5. **提交**：`submit` 交上去，拿到 submission ID 和领奖码（claim code），妥善保存。
6. **等出分**：裁判打分需要几小时，出分后看名次。分数是胜率（和固定对手两两比较），不是绝对分。

## 想拿高分的经验（实测）

**裁判只看两样东西**：截图拼成的 contact sheet + 标题/源码大纲（约 1536 token）。看不见的等于零分。

1. **标题要写清系统和数量**。前几名游戏标题全是“16 升级、12 遗物、2 Boss、18 配方”这种清单；我最早的标题只有一句“guide the lost ships home”，零系统，白白丢分。新闻图同理，标题要写“45 条、15 张配图、7 个地区”。
2. **封面必须是内容最密的游玩画面**，不能是文字标题屏。我 v3 的封面是深色文字面板，完全看不到玩法，输就输在这。
3. **内容量要够**。前 100 名作品平均约 1MB，我 v2 才 447KB。新闻图要多条新闻、多配图、多地区。
4. **完整循环要可见**：开始、玩法、得分、胜利/失败、重开按钮，都要在截图里出现。
5. **提交记录要用你的原话**。run record 的 prompt 必须一字不差用你自己的话，改写会被平台拒（我 v2 首版就因此被拒过）。
6. **别一天交太多次**。同一比赛一天交 3 条会被限流（HTTP 429），想重提要隔开。
